# Presentation Plan: COVID-19 Radiography GAN Deep Learning Project

## Slide 1: Project Title

**Slide content**

- COVID-19 Chest X-ray Generation and Classification
- Deep Learning project using GAN + CNN
- Dataset: COVID-19 Radiography Database
- Training platform: Google Colab GPU
- Local application: Flask web app

**What to say**

"This project is about using deep learning for COVID-19 chest radiography images. The goal is to generate synthetic chest X-ray images using a GAN, then use both real and synthetic images to train a classifier. The heavy training was done on Google Colab with GPU, and the final models are served in a local Flask web app."

---

## Slide 2: Problem Statement

**Slide content**

- Medical image datasets can be limited or imbalanced.
- Deep learning models need many examples to generalize well.
- GANs can generate synthetic images to support training.
- Classifier predicts chest X-ray category from an image.

**What to say**

"In medical deep learning, data is very important. Sometimes datasets are small, expensive, or imbalanced between classes. This project explores whether synthetic images generated by a GAN can help build a better classifier for COVID-19 radiography images."

---

## Slide 3: Project Objectives

**Slide content**

- Prepare a COVID-19 radiography image dataset.
- Train a conditional DCGAN to generate images by class.
- Generate synthetic COVID-19 radiography images.
- Train a CNN classifier using real and synthetic images.
- Evaluate classification performance.
- Build a Flask app for generation and classification.

**What to say**

"The project has two main deep learning parts. The first is image generation using a conditional GAN. The second is image classification using a CNN. At the end, both models are connected to a simple web application."

---

## Slide 4: Dataset Used

**Slide content**

- Dataset: COVID-19 Radiography Database
- Used the chest X-ray image classes and ignored mask folders.
- Classes:
  - `covid`
  - `normal`
  - `viral_pneumonia`
  - `lung_opacity`
- Data split: train/test using stratified split

**What to say**

"In this version, we use the Kaggle COVID-19 Radiography Database. The dataset is organized into four chest X-ray classes: covid, lung opacity, normal, and viral pneumonia. Mask folders are ignored because this project focuses on classification and image generation, not segmentation."

---

## Slide 5: Data Preparation Pipeline

**Slide content**

- Download dataset from Kaggle.
- Extract raw image folders.
- Detect radiography class folders automatically.
- Create folder structure:

```text
data/covid_radiography/
  train/class_name/*.jpg
  test/class_name/*.jpg
```

- Resize and normalize images during training.

**What to say**

"The data preparation script downloads and organizes the dataset into a format that PyTorch can use easily. Each class has its own folder. The split is stratified, which means each class keeps approximately the same proportion in train and test."

---

## Slide 6: Why Google Colab Was Used

**Slide content**

- Local machine is not ideal for deep learning training.
- GAN training is computationally expensive.
- Google Colab provides GPU acceleration.
- Training notebook:
  - `run_medical_gan_colab_fixed.ipynb`
- Results saved back to Google Drive.

**What to say**

"We used Google Colab because GANs and CNNs train much faster on GPU. Instead of training on the local machine, the project is packaged into a zip file, uploaded to Google Drive, and trained in Colab. After training, the checkpoints are copied back to the local project."

## Slide 8: GAN Model

**Slide content**

- Model type: Conditional DCGAN
- Input:
  - random noise vector
  - class label
- Output:
  - synthetic COVID-19 radiography image
- Generator learns to create images.
- Discriminator learns to distinguish real from fake.

**What to say**

"The GAN is conditional, meaning it does not generate random images only. It receives a class label, so we can ask it to generate a specific tissue class. The generator creates images, while the discriminator tries to detect whether images are real or fake."

---

## Slide 9: GAN Training Process

**Slide content**

- File: `train_gan.py`
- Input: `data/covid_radiography/train`
- Output checkpoint:

```text
checkpoints/covid_dcgan.pth
```

- Sample grids saved in:

```text
generated_samples/
```

**What to say**

"During GAN training, the generator and discriminator improve together. At different epochs, sample image grids are saved so we can visually inspect whether the GAN is learning useful chest X-ray patterns."

---

## Slide 10: Synthetic Image Generation

**Slide content**

- File: `generate_synthetic.py`
- Uses trained generator checkpoint.
- Creates class-organized synthetic dataset:

```text
synthetic_covid_images/
  COVID radiography_adenocarcinoma/
  COVID radiography_benign_tissue/
  COVID radiography_squamous_cell_carcinoma/
```

**What to say**

"After training the GAN, we use it to generate additional images. The output is organized by class, just like the real dataset. These generated images are later added to the classifier training set."

## Slide 11: CNN Classifier

**Slide content**

- File: `classifier.py`
- Model: Simple CNN
- Input: COVID-19 radiography image
- Output: class prediction
- Classes:
  - adenocarcinoma
  - benign tissue
  - squamous cell carcinoma

**What to say**

"The classifier is a convolutional neural network. It takes an image as input and predicts one of the three chest X-ray classes. CNNs are commonly used for image classification because they learn spatial features such as texture, shapes, and patterns."

**Slide content**

  - real COVID-19 radiography images

## Slide 18: Important Commands

**Slide content**

```bash
python download_dataset.py --output_dir data/covid_radiography_raw
python prepare_dataset.py --raw_dir data/covid_radiography_raw --output_dir data/covid_radiography --test_size 0.2 --overwrite
python train_gan.py --train_dir data/covid_radiography/train --epochs 50 --batch_size 32 --image_size 64
python generate_synthetic.py --checkpoint checkpoints/covid_dcgan.pth --match_real_dir data/covid_radiography/train --out_dir synthetic_covid_images
python train_classifier.py --real_train_dir data/covid_radiography/train --synthetic_train_dir synthetic_covid_images --test_dir data/covid_radiography/test
flask --app frontend/app.py run --host 127.0.0.1 --port 5000
```

**What to say**

"These are the main commands behind the project. In practice, the training commands are run in Google Colab, while the final Flask app can be run locally after copying the trained checkpoints back."

## Slide 19: Limitations

**Slide content**

- Not a clinical diagnostic tool.
- GAN image quality depends on training time.
- Simple CNN can be improved.
- Needs careful validation before real medical use.
- Synthetic images should not replace expert-labeled data.

**What to say**

"This project is educational and experimental. It is not a real medical diagnosis system. To make it stronger, we would need better validation, stronger models, more training, and expert medical review."
